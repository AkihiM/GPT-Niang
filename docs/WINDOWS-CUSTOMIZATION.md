# Windows 定制说明

本分支基于 [T7moris/GPT-Niang](https://github.com/T7moris/GPT-Niang) 的 1.3.4 源码，整理此前在 Windows 挂件上完成的角色与界面定制。上游的 Business 个人额度适配、Windows DPI 定位方案及 macOS 源码保持在当前基线中；本次新增功能面向 Windows，未移植到 macOS，也未完成 macOS 真机验证。

## 角色图库

在右键菜单的「外观设置」中点击「形象」入口，打开「选择你喜欢的形象」。点选卡片立即切换并关闭图库，重新启动后恢复所选形象。

- 图库使用与菜单一致的紫色圆角样式和细滚动条，可拖动顶部，按 Esc 或右上角 × 关闭。
- 末尾始终显示「＋ 添加形象」卡片；推荐透明背景 PNG，图片按比例显示，保留背景与透明留白。
- 支持 PNG、JPG / JPEG、BMP、GIF；GIF 仅使用第一帧作为静态形象。导入限制为 20 MB、边长 4096 像素及 1600 万像素。
- 导入时保存一份规范化的 PNG 副本，之后移动原图不会影响已导入形象。图片及用户图库清单保存在本机数据目录。
- 自定义卡片上的 − 按钮可移除形象，并提供「撤销移除」。内置形象不可移除；移除当前形象，或所选图片损坏、缺失时，回退到「龙娘1」。

图片切换同步更新透明区域点击判断及颜色效果蒙版。导入、移除与恢复使用原子清单更新，并在失败时回滚；文件路径检查拒绝目录链接跳转。角色和蒙版使用等比缩放，WPF 启用 HighQuality 图像采样，以改善缩小时的边缘。

公开仓库只附带上游的「龙娘1」。个人使用的第三方龙娘2原图及 AI 线条增强版未收入仓库；角色导入功能可供用户添加自己有权使用的素材。

## 额度气泡与菜单

- 隐藏「剩余额度」标题，额度信息整体居中。周期名称使用正常粗细，百分比保留粗体；重置提示改为淡灰色，并与进度条留出间距。
- 单周期布局加大文字和进度条，方便在 80% 挂件大小下阅读；双周期布局收紧两组间距，保持信息集中。
- 单周期采用字号 20 / 28 / 14（周期 / 百分比 / 重置提示），进度条宽 184、高 9；双周期采用字号 17 / 22 / 12，进度条宽 168、高 5。
- 刷新图标移到气泡底部中央，使用浅灰色。独立覆盖层使图标与人物重叠时仍可正常点击；左右镜像时图标与文字保持正向。
- 形象入口使用打开图标表达操作，菜单与图库保持一致的配色和滚动条风格。

两秒倒计时、随后三秒显示固定重置时刻、五秒后自动收起，以及按本机时区显示时间，均为上游已有行为。

## 其他修正

- 修复音量恢复时误用整数 `Math.Min` / `Math.Max` 重载，导致 0.35、0.9 等小数音量被舍入的问题。
- 为启动早期的 DPI 查询增加空窗口句柄保护，并增加角色图库控制请求、所选角色状态和错误诊断。
- 新增角色辅助、图像渲染及启动检查，覆盖导入与移除、异常回退、透明区域、宽长图片、左右镜像、多个缩放比例及额度布局。
- 在原有 33 条内置语录外保留用户提供的「好女孩……」，共 34 条。

## 发布与许可

创建 Fork 不要求额外的修改日志。本文件记录定制范围；上游版本历史仍见 [更新记录](../更新记录.md)。当前仅提供功能分支源码，没有单独发布改版 Release，也未向上游提交 PR。项目首页中指向 T7moris/GPT-Niang 的下载链接均为上游正式版。

本分支不包含个人导入图片、图库用户清单、账号与额度快照、运行日志、安装后的配置、备份或本机路径。内置角色清单属于源码；它与本机数据目录的用户图库清单用途不同。
